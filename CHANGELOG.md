# Changelog

## [1.1.0] - 2026-10-15

### Added
- **NDIS Guide** (`skills/ndis-guide/`): Australian NDIS navigation, backed by a shipped library of 59 current official documents in `shared/ndis/`: all operational guideline documents, the consolidated NDIS Act 2013 (as at 1 October 2026), the (Supports for Participants) Rules, the pricing schedule 2026-27, and the 2026 law-change briefings. Answers quote the documents with source and date, never model memory.
- **`scripts/fetch-ndis-docs.py`**: one-command refresh of the NDIS library.

## [Unreleased]

### Added
- **ADHD Tax Shield** (`skills/adhd-tax-shield/`): the acute end of life admin, deliberately split from Money and Admin Ally, which keeps the standing system. Three pieces: a three-line scary-mail de-escalator (is anything actually happening right now, the single action and its date, an offer of two 90-second steps), a trial and renewal register that reminds five days early and records the direct cancellation path, and a four-sentence waiver and extension drafter that asks without grovelling and without disclosing a diagnosis. Not financial, tax or legal advice; severe debt distress goes to the National Debt Helpline on 1800 007 007.
- **RSD Tone Translator** (`skills/rsd-tone-translator/`): the words skill, split three ways from its neighbours. Emotion Regulation Coach owns the spiral, Work Advocate owns rights and disclosure, this one owns the sentence. Three workflows: an ambiguous message decoder that separates the literal text from what threat-brain added, gives two or three ordinary explanations, and offers the cheapest one-line test rather than reassurance; a converter that turns exhausted bullet points into Warm Colleague, Neutral Boundary or Firm Self-Advocacy, or strips a 600-word email to the two things that actually need doing; and accommodation requests framed as working conditions, so no diagnosis has to be disclosed. Includes an explicit section on telling RSD apart from real mistreatment, because flattering the user is as wrong as amplifying them.
- **Dopamine Menu** (`skills/dopamine-menu/`): novelty as a need rather than a treat. Builds a standing four-part stimulation menu (2 to 5 minute entrées that do not hijack attention, 30 minute mains in real special-interest flow, sides for pairing with chores, and desserts with an exit ramp built into the format rather than willpower), then puts every routine on file in three pre-agreed tiers: Full Day, Low-Battery Day, and a Survival Day that is genuinely achievable at zero energy. The bad day contains no decisions, only selection. Also owns novelty rotation, because satiation is why good routines go flat. Deliberately split from Routine Builder, which designs the base routine: that skill builds it, this one keeps it alive. **Note:** the traffic-light capacity mode lives in the NeuroFamily family repo and is not implemented here, so this skill reads the `energy-log.md` signal instead and maps its three tiers one to one if capacity mode is ever ported.

- **Spoon Collision Radar** (`templates/artifacts/spoon-collision-radar.html`): a calendar shows overlapping clock times; this shows overlapping nervous systems. Seven-day grid where each event is scored 1 to 5 on masking and social load, sensory intensity, and executive demand, with recovery blocks that subtract so a real rest day can pull a bad week back. Flags any day over a daily threshold and any 48-hour window over a window threshold, naming the biggest driver, days before the crash rather than the morning after. Each collision gets a swap scratchpad with low-demand suggestions (move the meeting to async, block a dark-room buffer, switch dinner to Survival Tier). Zero external requests, localStorage with JSON export and import, one-page A4 landscape print.

- **`scripts/ndis_watch.py`** and **`schedules/ndis-watch.md`**: a fortnightly watch over ten official NDIS sources plus the whole shipped library. Silent when nothing has moved; writes `shared/ndis/changes/<date>.md` when a source changes, and `--refresh` pulls the latest library. Blocked pages keep their previous hash.
- **`scripts/install.py`**: one command replaces the hand-copying that used to be steps 3 and 4 of `INSTALL.md`. Copies all fifteen skills, the three identity files (`SOUL.md`, `AGENTS.md`, `profile.yaml`), the example config and the personal folder in one pass, auto-detecting the Hermes profiles directory per platform. `--dry-run` shows the plan without touching anything; `--profile`, `--folder` and `--profiles-dir` override the defaults. It never overwrites a config or an edited identity file without `--force-config` or `--force-identity`, and it never overwrites a folder note. Standard library only, because it has to run on a bare Python before anything else works.
- **`requirements-ndis.txt`**: the three optional packages needed only to re-scrape the NDIS library, with a comment making clear that installing and using the agent needs no third-party packages at all.
- **`tests/test_repo_integrity.py`**: a zero-dependency `unittest` suite guarding the things that rot when skills are added or ported. It checks that every skill is routed and self-describing, that the folder filenames stay canonical, that no personal path or credential handling creeps back in, that artifacts stay offline and printable, and that every shipped script still compiles. Tests for helper scripts skip until the script exists, then enforce its interface. Known-open debts are marked `expectedFailure`, which turns **red** when the debt is paid, so the marker cannot rot silently.
- **Three folder templates**, bringing the folder to ten files: `shared/admin.template.md` (open items with a next-tiny-step column, a trial and renewal register that reminds five days early and keeps the cancellation path in the row, and closed admin wins), `shared/routines.template.md` (the three day tiers agreed in advance, with blocks for morning, meds, meals and evening shutdown), and `shared/dopamine-menu.template.md` (entrées, mains, sides and desserts with an exit ramp, plus rotation notes). Skills had been reading and writing all three of these files since 1.1.0, and setup created none of them.

### Fixed
- **`ndis-guide` was never fully registered.** It shipped in 1.1.0 as the twelfth skill, but `AGENTS.md` still said eleven skills, the routing table had no row for it, and none of the twelve per-skill team lists mentioned it. All thirteen team lists, the routing table and both counts now agree.
- **The NDIS watch no longer handles credentials unsafely.** `scripts/ndis_watch_cron.sh` used to scrape a token out of the credential file and pass it on the `git push` command line, where any other process on the machine can read it and a failed push prints it into the log. It now pushes with whatever credential helper, `gh auth setup-git` or SSH key you already have, and says so plainly when no non-interactive credentials are available. The commit identity is configurable via `GIT_AUTHOR_NAME` and `GIT_AUTHOR_EMAIL` instead of being hardcoded.
- **`fetch-ndis-pages.py` no longer assumes one machine's browser path.** A hardcoded home directory meant Chromium could not be found for anybody else. Playwright's own default is now used, with `PLAYWRIGHT_BROWSERS_PATH` left to the user.
- **`INSTALL.md` step 3 named a folder that does not exist.** It told you to copy from `ndagent-solo-hermes-agent/` while step 1 cloned `neurodivergeagent-solo-hermes-agent/`, so a straight copy-paste failed. The manual path is now correct and the installer is the recommended route.
- **The example config's OpenRouter model slug was missing its vendor prefix.** `deepseek-v4-flash` is not an OpenRouter ID and fails at request time; it is now `deepseek/deepseek-v4-flash`, with a comment explaining the prefix and the `:nitro` variant form.
- **`work.md` and `health.md` were files that never existed.** Twelve of the fifteen skills closed their session-housekeeping line with "anything else where it belongs (`work.md`, `health.md`, `connections.md`)", but the templates ship as `work-notes.md` and `health-notes.md`, so setup never created the short names. An agent following those instructions wrote to one file while the user's notes sat in another, with no error raised on either side. All twenty-three references now use the canonical names, and the integrity suite fails if the short forms return.
